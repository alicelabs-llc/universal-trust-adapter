## Skill Architecture

Each skill follows the standardized AgentSkills specification:

```
skill-name/
├── SKILL.md              # Main skill definition (trigger conditions, usage, commands)
├── scripts/              # Executable code (Python, CLI tools)
├── references/           # Documentation loaded into context
└── assets/              # Templates, boilerplates, static files
```
