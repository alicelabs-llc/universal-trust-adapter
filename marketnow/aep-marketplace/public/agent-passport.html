The 3 problems we solve

🔴 Problem 1: Identity
Agents have no verifiable identity. Anyone can impersonate any agent. RSAC 2026 called this "a top-tier security concern." 9 agent identity projects were created in 2026 alone.
🔴 Problem 2: Trust
No way to verify an agent is trustworthy before interacting. 492 MCP servers were found without basic authentication. Agents blindly trust each other.
🔴 Problem 3: Encryption
Agent-to-agent communication is plaintext. No standard for encrypted messaging between agents. Interceptions and MITM attacks are trivial.

The solution: Agent Passport

✅ Identity — Each agent generates an Ed25519 keypair. The public key IS the agent's identity. MarketNow issues a signed Passport that binds the identity to a trust score.
✅ Trust — The Passport includes a Sentinel trust score (0-10) based on security audits. Agents reject connections from passports with score < 5.
✅ Encryption — Agents derive a shared secret via X25519 ECDH. All messages encrypted with AES-256-GCM. Every message is signed with Ed25519.

How it works

Step 1: Agent generates keypair

# Generate Ed25519 signing keypair (for identity)
openssl genpkey -algorithm Ed25519 -out agent_private_key.pem
openssl pkey -in agent_private_key.pem -pubout -out agent_public_key.pem

# Generate X25519 encryption keypair (for messaging)
openssl genpkey -algorithm X25519 -out agent_enc_private.pem
openssl pkey -in agent_enc_private.pem -pubout -out agent_enc_public.pem

Step 2: Request Passport from MarketNow

Step 3: Agent-to-agent handshake

# Agent A sends passport to Agent B
{ "passport": {...}, "nonce": "random_32_bytes" }

# Agent B verifies with MarketNow
GET https://marketnow.site/api/passport?verify=AP-2026-00001
→ { "valid": true, "trust_score": 10, "revoked": false }

# Both agents derive shared secret (X25519 ECDH)
shared_secret = X25519(my_private_key, their_public_key)

# All messages encrypted with AES-256-GCM
encrypted = AES_256_GCM(plaintext, shared_secret, random_iv)
signed = Ed25519_sign(encrypted, my_private_key)

# Message format:
{

Step 4: Revocation (if agent goes bad)

# Check revocation list
GET https://marketnow.site/api/passport?revoked=1
→ { "revoked_passports": ["AP-2026-00042"], "total_revoked": 1 }
