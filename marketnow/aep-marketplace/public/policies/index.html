Refund Policy

Since buyers install all skills for free, there are no buyer refunds needed. For sellers who subscribe to Sentinel:

  • Pro-rated refund within 7 days of subscription start
  • No refund after 7 days, but subscription can be cancelled at any time
  • Commission on completed sales is non-refundable

Dispute Process

If a buyer has a dispute about a skill (malware, misrepresentation, broken):

  1. Report via POST /api/report with skill_id and evidence
  2. MarketNow investigates within 48 hours
  3. If confirmed, skill is quarantined and seller's Sentinel subscription is reviewed
  4. For USDC payment disputes: contact disputes@alicelabs.site with transaction hash
