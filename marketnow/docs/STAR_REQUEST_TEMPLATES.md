# 🙏 Pedir Stars — Plantillas para redes

GitHub stars son la métrica #1 de credibilidad social. Tienes 1 star después de 90 issues y 15 artículos. Hay que pedirlos explícitamente.

## Regla de oro
**No pidas stars en cada post.** Pídelos 1 de cada 3 posts, y siempre con un CTA específico.

---

## Plantilla 1 — Cierre de post en dev.to (añadir al final)

```
---

If you found this useful, please ⭐ the MarketNow repo on GitHub:
[github.com/alicelabs-llc/marketnow](https://github.com/alicelabs-llc/marketnow)

Stars help other developers discover the project. It's free for you and means a lot to me.
```

---

## Plantilla 3 — Comentario en issues de otros repos

Cuando respondas issues en otros repos (awesome-mcp-servers, etc.), añade al final:

```
PS: If MarketNow is useful to you, a ⭐ on the repo helps others discover it:
https://github.com/alicelabs-llc/marketnow
```

## Cuándo usar cada plantilla

| Plantilla | Cuándo usarla | Frecuencia |
|-----------|---------------|------------|
| 1 (dev.to) | En cada nuevo artículo de dev.to | Siempre |
| 2 (Tweet) | Cuando publiques un thread importante | 1 vez/semana |
| 3 (Comentario) | Cuando respondas issues en otros repos | Siempre |
| 4 (Reddit) | En r/MCP o r/ClaudeAI | 1 vez cada 2 semanas |
| 5 (README) | Agregar al README.md del repo | Una sola vez |

---

## Meta

- **Objetivo a 30 días:** 50 stars (de 1 a 50)
- **Objetivo a 90 días:** 200 stars
- **Estrategia:** Pedir en cada interacción pública, sin ser molesto
