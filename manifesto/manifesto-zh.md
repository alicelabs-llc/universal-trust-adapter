# 陌生者宣言

**要求会员资格的信任不是信任，那是宾客名单。**

当代理与世界谈判——购买、销售、调用工具、签署意图——总有人想把一个问题的答案卖给你：*这个能信吗？*

我们拒绝卖答案。我们公布证据。以下是我们构建所依据的规则：

**1. 陌生者必须能够验证。**
如果证明要求你在网络之内——会员资格、密钥、关系——那是许可，不是证明。许可没问题，但别叫它信任。

**2. 失败即关闭。**
当证据缺失、过期或无法验证时，答案是*不行*。没有证据不等于清白；它是一个未回答的问题——而未回答的问题无权让资金流动。

**3. 测试测试者。**
验证者本身就是断言的一部分。没人探测过的评分引擎，就是未经验证的证明。我们用自己的 runner 对抗试图击败它的变异体——并公布结果。

**4. 真理从字节推导。**
元数据会说谎，sidecar 会说谎，仪表盘会说谎。但对规范字节的签名，谁也说服不了它挪动立场。真理靠推导，不靠宣布。

**5. 时效是双向的。**
日期在未来的凭证，和日期在过去的一样坏。窗口有下界和上界。两个都查，否则什么也别查。

**6. 吊销是签发的一部分。**
公布证明却不公布如何撤销它，等于只公布了一半的承诺。密钥、runner 和策略必须可吊销——而一个离线的验证者必须能凭一张签名便签追上进度。

**7. 锚点住在锚定者控制之外。**
"发布过什么"的记录，必须住在发布者改写不了的地方。我们把每次发布锚定进公开透明日志（Rekor / Sigstore），其包含证明用我们并不持有的密钥来验证。

**8. 无密钥，无门禁。**
要求 API key 的验证，是可以被关掉、涨价或记录的验证。验证应该离线运行、无需密钥、毫秒完成、任意设备。

**9. 可复现，否则等于没发生。**
如果陌生者无法从公开源码重建工件并得到相同字节，那工件就是信仰对象。我们的工件逐字节重建，并给出证明。

**10. 收据，而非路线图。**
承诺是营销。收据是无人能改的日志里的校验和。给我看命令，别给我看幻灯片。

任何人都可以审计我们。命令就在这里。
